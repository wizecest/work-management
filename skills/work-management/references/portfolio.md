# 管理层审视

用于检查整个项目组合的管理成效，默认只读；不替代今日执行安排。

全部范围内项目都检查目标、截至日的状态、计划与承诺、近期变化、风险、处理措施、等待对象和需决策事项。正常项目每个一行；缺少资料的不能写成正常。

深入检查：关键目标偏差；多轮协调仍无可验证结果；投资、质量、合同、审批或资源风险；同一问题反复出现；超过经办权限仍缺升级材料；跨项目资源冲突；会改变判断的数据冲突。

对措施问清三个问题：想改变什么、实际改变什么、是否核验。没有结果证据就写“尚不能证明有效”。没有当时应当知道的资料，不倒推责任；只评价可见动作和结果，不给个人打分或推断性格。

固定输出：

1. 总体判断。
2. 全部项目检查结果。
3. 需要深入审视的项目：目标、偏差、后果、依据和应核对的问题。
4. 干预是否有效。
5. 本应更早发现的风险：说明当时可获得的信号；证据不足时标待核实。
6. 需要升级、协调或决策：事项、处理层级、所需材料、最晚时间。
7. 管理做法反馈：基于事实给可执行改进，不作人格评价。
8. 信息缺口与人工纠偏。

每个异常项目先展开最关键的 1–3 项，其他已识别异常仍需列出。分析不自动更新项目状态、日志或今日成果；用户要求保存时只保存本次报告。
