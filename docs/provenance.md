# 来源与改编说明

本包从用户维护的 PM-Obsidian `work-management` 工作管理技能提炼，公开发布版本从 0.1.0 起独立编号，不沿用原技能的内部版本号。原技能元数据声明 MIT；本包保留该许可方式。未引入第三方脚本或运行库。

## 本次覆盖

| 原有能力或约定 | 发布版入口 | 适配方式 |
| --- | --- | --- |
| work-management 主技能及自然语言入口 | SKILL.md | 保留模式路由，移除绝对路径与私有例子 |
| work-daily 当前六段正文及附录 | references/daily.md | 统一公开版今日结构，不复制旧版冲突模板 |
| 日周月季年总结 | references/summaries.md | 保留成果、承诺、风险和复盘，去除私有保存位置及强制画像判断 |
| 总经理／管理层审视 | references/portfolio.md | 全项目覆盖与管理效果核对 |
| 对外台账 | references/ledger.md | 时间线、问题措施对应和对外表述 |
| 日志、补同步、复盘和素材提炼 | references/records.md | 资料模式与事务系统分别处理 |
| Runtime、ProjectStatus 和报告保存依赖 | docs/integration.md | 声明适配合同，不复制系统实现 |
| 主动简报 | docs/integration.md | 保留授权与去重约定，不附带调度或通知服务 |

## 没有带入的内容

真实项目资料、工作日志、历史执行日志、用户画像、账号配置、凭证、本机路径、旧版决策树配置和 Shell 脚本均未复制。旧元数据中的“自主学习”“无依赖自动同步”等表述不作为本包能力。

公开版的安装、检查、打包脚本是本次独立编写的发布辅助工具，不承担业务状态推导或事实事务。
