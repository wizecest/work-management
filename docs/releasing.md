# 发布说明

本目录是独立作品仓库。只发布显式清单中的文件；本地运行资料放在 `private/`、`local/` 或目标工作空间，均不属于发布包。忽略规则只是防止误加入的补充措施，不能替代内容检查。

## 本地检查

```text
python scripts/check_release.py
python -m unittest discover -s tests -v
```

检查内容包括：发布清单路径不越界、不含重复项、不经过符号链接或 Junction；清单文件齐全；没有额外未登记的公开文件；Markdown 本地链接存在；UTF-8 可读；常见密钥格式和绝对个人路径扫描；技能头部基本结构。自动扫描只覆盖所列模式，无法证明所有敏感内容都不存在；发布前仍应阅读本次变动。

## 打包

```text
python scripts/build_release.py --output-dir <仓库外的压缩包目录>
```

打包前会再次检查。输出 `work-management-0.1.0.zip`，顶层为 `work-management/`，附一个 SHA-256 校验文件。目标文件已存在则停止，不覆盖旧发布包。需要调整内容时先修改文件清单，并重新检查。

## GitHub 发布

在本目录检查 Git 变动，建立初始提交，并绑定自己新建的空 GitHub 仓库，再推送。仓库建议名称为 `work-management`，简介可用“中文工作管理 Agent 技能：今日安排、日志、周期总结、管理层审视与对外台账”。不要提交父目录的本机发布记录、其他作品或真实业务资料。

本包准备完成不代表已经创建远端仓库、推送或发布 Release。上传时使用已确认的账号与仓库，凭证由 GitHub 或宿主管理，不写进本项目。版本变化时同步 `VERSION` 和说明，先完成检查再生成新包。
